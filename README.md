# React + Node.js Project Template

## Setup Instructions

1. Navigate to the `backend` directory and run `npm install`.
2. Navigate to the `frontend` directory and run `npm install`.
3. Start the backend: `npm start` (inside the `backend` directory).
4. Start the frontend: `npm start` (inside the `frontend` directory).
